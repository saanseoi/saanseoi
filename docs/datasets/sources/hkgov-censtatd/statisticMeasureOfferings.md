# Statistic measure offerings

## v1

### EN

SaanSeoi publishes each reviewed C&SD measure with a short accessible name and a
separate precise description. The name gives a general reader the statistical concept at
a glance, especially where a dataset has only one field or repeated source headings
would make the selector hard to scan. The description states the exact measurement,
population or geographic inclusion criteria, exclusions, period, and unit where those
distinguish the published value.

Names do not add representation language such as “Proportion of”, “Percentage
distribution of”, or “Total” merely because it appears in a publisher heading. Nor do
they repeat a unit or a source-table label. Those facts are retained in the description
and reviewed metadata, so an offering can stay readable while preserving the publisher's
specific definition. A name is therefore not a shortened definition: the two fields
serve complementary purposes.

### ZH-HANT

山水會把每項經審核的 C&SD 指標發布為一個 offering，並提供簡短易讀的名稱及另一則精確描述。名稱讓一般讀者一眼掌握統計概念，特別適用於只有一個欄位的資料集，或重複來源標題會令選擇器難以瀏覽的情況。描述則交代已發布數值所依據的確切量度、人口或地理納入條件、排除條件、時段及單位（如這些因素能區分該數值）。

名稱不會只因發布者標題包含而加入「比例」、「百分比分布」或「總計」等呈現語言，也不會重複單位或來源表格標籤。這些資料保留於描述及經審核的中繼資料，讓 offering 既易讀又能保留發布者的具體定義。因此，名稱不是縮短版定義：兩個欄位用途互補，必須一併審核。

### ZH-HANS

山水会把每项经审核的 C&SD 指标发布为一个 offering，并提供简短易读的名称及另一则精确描述。名称让一般读者一眼掌握统计概念，特别适用于只有一个字段的数据集，或重复来源标题会令选择器难以浏览的情况。描述则交代已发布数值所依据的确切量度、人口或地理纳入条件、排除条件、时段及单位（如这些因素能区分该数值）。

名称不会只因发布者标题包含而加入「比例」、「百分比分布」或「总计」等呈现语言，也不会重复单位或来源表格标签。这些资料保留于描述及经审核的元数据，让 offering 既易读又能保留发布者的具体定义。因此，名称不是缩短版定义：两个字段用途互补，必须一并审核。
